# Cool media players
Built as an embedded media device, this project pairs an MP3 decoder module with a micro-controller to handle offline audio playback directly to connected speakers or headphones. Users can interact via physical hardware buttons, an onboard display, or remotely control media playback and manage the local library over a local network connection.
